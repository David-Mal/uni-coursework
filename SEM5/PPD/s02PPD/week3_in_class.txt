The in-class assignment for **week 3** is:

-The **scalar product of two vectors**, A and B, each containing *n* real-number elements, resulting in vector C (also with *n* elements).

Language: C++.

x * y = x1y1 + ... + xnyn = scalar product

In this way, each thread computes a local sum, and the global sum is ultimately calculated by having each thread update a global variable.

Array representation:
1. static allocation (note: not stack allocation within a function)
2. dynamic allocation
3. vector<double>

Explicit creation of *p* threads to share the workload:

**a) Linear distribution** 
(splitting the vectors into *p* relatively equal **segments**—with a maximum difference of 1 between segment sizes);

the vectors are not physically split; instead, 
each thread sums elements from a start position to an end position (calculated based on the thread number).

**b) Cyclic distribution**—thread *i* sums elements at indices *i*, *i+p*, *i+2p*, etc.

Testing begins with a verification step (n=10, p=3), 
followed by increasing *n* (and varying *p*—e.g., 4, 6, 8, 16) 
until the time calculated for the parallel sum is less than that of the sequential sum. 
The challenge of overcoming the overhead associated with thread creation and management should be highlighted.

To avoid dealing with excessively large numbers, vectors can be initialized with values in the 1–100 range. 
File I/O is not required for the in-class assignment; 
simple initialization via a dedicated function suffices.
